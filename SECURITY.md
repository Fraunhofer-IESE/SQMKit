# Security Policy

## Supported Versions

SQMKit is currently in early development. Security fixes are applied to the
latest release on the main branch.

| Version | Supported |
| ------- | --------- |
| 0.1.x   | Yes       |

## Reporting a Vulnerability

Please do not report security vulnerabilities in public GitHub issues.

Report them privately through GitHub's **Security Advisories** feature:

1. Open the repository's **Security** tab.
2. Select **Report a vulnerability**.
3. Include a description of the issue, steps to reproduce it, and any
   relevant logs or proof of concept.

If GitHub Security Advisories are not available, contact the maintainers
directly using the email addresses listed in `pyproject.toml`.

We will acknowledge reports as soon as possible and keep you informed about
the investigation and any fix.
