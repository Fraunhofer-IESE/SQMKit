# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability, please **do not** open a public issue.
Instead, send an email to security@example.com with a description of the issue,
the steps to reproduce it, and any other relevant information.

We will respond to your report within 5 business days and work with you to
understand and resolve the issue.

## Contact

For security-related questions, reach out to the security team at
security@example.com.
